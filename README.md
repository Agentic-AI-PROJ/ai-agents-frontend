# AI Agents Frontend

A modern, responsive, and feature-rich frontend for interacting with AI Agents, built with **Vite**, **React**, and **HeroUI**. This application provides an intuitive interface for chatting with agents, visualizing data with diagrams, and managing agent configurations.

## 🚀 Features

- **Interactive Chat Interface**:
  - Real-time streaming responses.
  - **Markdown Rendering**: Rich text formatting for agent responses.
  - **Mermaid Diagrams**: Automatic rendering of flowcharts and diagrams generated by agents.
  - **Code Highlights**: Syntax highlighting for various programming languages.
- **Visual "Card" System**: Agents and conversations are organized into detailed "Cards" for easy navigation and management.
- **Admin Dashboard**: a dedicated space for managing users, agents, and system configurations.
- **User Management**: Authentication, profile management, and role-based access.
- **Modern UI/UX**:
  - Built with **HeroUI** (formerly NextUI) for a premium look and feel.
  - Fully responsive design using **Tailwind CSS**.
  - Dynamic interactions with **Framer Motion**.

## 🛠️ Technology Stack

- **Core**: [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com), [HeroUI](https://heroui.com)
- **State & Routing**: [React Router DOM](https://reactrouter.com/), Context API
- **Utilities**:
  - [Axios](https://axios-http.com/) for API requests.
  - [Mermaid](https://mermaid.js.org/) for diagram generation.
  - [Lucide React](https://lucide.dev/) for icons.

## 📦 Installation

To get started with the development environment:

1.  **Clone the repository** (if you haven't already):
    ```bash
    git clone https://github.com/your-username/ai-agents.git
    cd ai-agents/ai-agents-frontend
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Environment Setup**:
    Ensure you have the necessary environment variables configured (usually in a `.env` file) to point to your backend services.

## 🏃‍♂️ Usage

### Development Server
Start the local development server with hot-reload:
```bash
npm run dev
```
Access the app at `http://localhost:5173` (or the port shown in your terminal).

### Production Build
Create a production-ready build:
```bash
npm run build
```

### Preview Build
Preview the production build locally:
```bash
npm run preview
```

### Linting
Run the linter to ensure code quality:
```bash
npm run lint
```
